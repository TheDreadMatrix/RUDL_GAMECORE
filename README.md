🎮 RUDLGC Game Engine (Python)
🇺🇸 English

This repository contains a custom game engine written in Python using Pygame SDL2 bindings (pysdl2) and ModernGL.

✨ Features
🧱 Scene-based architecture
Easily manage game states using a flexible scene system.
⚡ Modern rendering with ModernGL
Fast and efficient GPU-based rendering.
🖥️ Cross-platform support
Works on Windows, Linux, and other platforms supported by SDL2.
🎮 Input handling system
Keyboard, mouse, and event management.
📦 Modular structure
Clean and extendable codebase for building your own games.
🔊 Multimedia support
Sound, textures, and animations support.
⚙️ Custom settings system
Easily configurable via Python and JSON||XML.
🚀 Goal

The goal of this project is to provide a flexible foundation for creating 2D/3D games while keeping full control over the engine internals.


🇷🇺 Русский

Этот репозиторий содержит кастомный игровой движок, написанный на Python с использованием pysdl2 и ModernGL.

✨ Возможности
🧱 Система сцен
Удобное управление состояниями игры через архитектуру сцен.
⚡ Современный рендеринг через ModernGL
Быстрый рендеринг с использованием GPU.
🖥️ Кроссплатформенность
Работает на Windows, Linux и других платформах, поддерживаемых SDL2.
🎮 Система ввода
Обработка клавиатуры, мыши и событий.
📦 Модульная структура
Чистый и расширяемый код для создания игр.
🔊 Поддержка мультимедиа
Звуки, текстуры и анимации.
⚙️ Гибкая система настроек
Настройка через Python и JSON||XML.
🚀 Цель

Цель проекта — предоставить гибкую основу для создания 2D/3D игр с полным контролем над внутренним устройством движка.
